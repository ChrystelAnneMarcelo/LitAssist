# LitAssist 
> **An Intelligent RRL Analysis & Chatbot Assistant**

LitAssist is an AI-powered Web Application designed to assist academic researchers, thesis students, and scholars in analyzing, synthesizing, and drafting **Reviews of Related Literature (RRL)**. It helps identify key research gaps, compare methodologies across papers, auto-extract scholarly metadata, and interact with literature via RAG-driven AI.


## Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **UI & Logic**: React 19, TypeScript
- **Styling**: Vanilla CSS Modules (`.module.css`), Google Fonts (*Fraunces*, *DM Sans*, *DM Mono*)
- **Icons**: Lucide React
- **APIs**: Crossref Academic API & Google Gemini REST API

## Getting Started

### Prerequisites

- Node.js 18+ installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ChrystelAnneMarcelo/LitAssist.git
   cd LitAssist
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
